# Release notes — 1.3.0-github-release

This GitHub consolidation preserves the documented 1.2.0 realtime modem profile
and packet format while adding:

- a clean public repository layout;
- MIT license proposal, citation and contribution metadata;
- hardware-free unit and end-to-end tests;
- GitHub Actions CI;
- conservative public RF defaults;
- an integrated deterministic QPSK performance tool;
- refreshed setup, operations, safety and troubleshooting documentation;
- source-only native build (compiled `.so` files are not committed).

This is a consolidation release, not a claim that every line is byte-identical
to every earlier development archive. Simulation and native decoder tests are
the acceptance source for the packaged repository.
